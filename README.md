# موقع فريق المسار — ALMASAR

موقع تعريفي ثابت مبني باستخدام HTML وCSS وJavaScript، باللغة العربية واتجاه RTL.

## الملفات
- `index.html`: محتوى الموقع وأقسامه.
- `styles.css`: الهوية البصرية والتصميم المتجاوب.
- `script.js`: تفاعلات القائمة والسنة.

## التشغيل المحلي
افتح `index.html` في المتصفح.

## النشر
يمكن ربط المستودع بـ Cloudflare Pages ونشر الموقع كملفات ثابتة:
- Framework preset: None.
- Build command: اتركه فارغاً (لا توجد خطوة بناء).
- Build output directory: `.` (جذر المستودع حيث يوجد `index.html`).
- Production branch: `main`.

## عناصر لم تكتمل بعد
- إضافة ملف العرض التقديمي التفاعلي الأصلي «مستقبل التعليم» إلى مجلد مستقل وربطه بالمعاينة.
- إضافة بيانات التواصل الرسمية بعد اعتمادها.
- استبدال الرسوم التوضيحية المؤقتة بلقطات حقيقية للمنتجات عند توفرها.
- مراجعة النصوص النهائية والروابط واختبار الموقع على أجهزة فعلية.

لا تعتبر هذه العناصر منجزة حتى يتم تنفيذها واختبارها.
